搜索框支持以下条件，可以组合使用，其余文字按全文关键词处理（中文关键词也能搜到）：

| 条件 | 示例 | 说明 |
|---|---|---|
| `from:` | `from:alice@example.com` | 发件人 |
| `to:` | `to:me@example.com` | 收件人 |
| `subject:` | `subject:发票` | 主题 |
| `account:` | `account:gmail` | 邮箱地址、名称或服务商 |
| `folder:` | `folder:sent` | `inbox` `sent` `junk` `trash` 或文件夹名称 |
| `is:` | `is:unread` | `unread` `read` `starred` `answered` |
| `has:attachment` | | 带附件 |
| `after:` / `before:` | `after:2026-10-01` `after:7d` | 日期范围，`before` 不含当天。也可以写相对日期：`today` `yesterday` `7d`（含今天在内的最近 7 天）`2w` `3m` `1y` |
| `label:` | `label:客户` | 标签 |
| `"..."` | `"季度预算"` | 精确短语 |
| `-` | `-广告` | 排除关键词 |

启用 AI 分析后还可以用：

| 条件 | 说明 |
|---|---|
| `category:` | `finance` `work` `personal` `verification` `shipping` 等分类 |
| `priority:` | `high` `normal` `low` |
| `is:needs-reply` | 需要回复 |
| `has:code` | 含验证码 |

中文写法也可以用，例如 `发件人:`、`未读`、`今天`、`近7天`、`之后:3个月`，提交时会自动换成上面的语法。要按「今天」「未读」这些词本身搜索时，加上引号。

## 补全和快捷操作

- **快捷筛选**：点一下空的搜索框，会显示快捷筛选（未读、星标、有附件、需回复、今天、近 7 天、近 30 天）和最近搜索。最近搜索只存在当前浏览器里。
- **补全**：输入条件名的开头（`发`、`分`、`fr`）就能补全。输入 `发件人:` 或 `收件人:` 后会联想联系人；`邮箱:`、`文件夹:`、`标签:`、`分类:`、`优先级:`、`之后:`、`之前:` 后面会列出可选的值。
- **键盘**：`↑` `↓` 选择，`Tab` 补全，`Enter` 搜索（选中某一项时用这一项），`Esc` 关闭。在页面任意位置按 `/` 聚焦搜索框。
- **条件标签**：搜索后，每个条件显示成搜索框下方的标签，点 × 去掉。
- **语法速查**：点搜索框右侧的「?」，点任意一项插入到光标处。

想用自然语言搜索时，点搜索框旁的「AI 搜索」，见 [AI 搜索](/zh/docs/ai/search/)。
