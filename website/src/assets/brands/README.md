# Brand logos

The logos on the home page show which mail providers, AI clients and model providers DaMail works with. Every logo is a trademark of its owner. Using one here does not mean that owner endorses DaMail.

| Files | Source | License |
|---|---|---|
| `gmail.svg`, `icloud.svg`, `qq.svg` | [Simple Icons](https://simpleicons.org) 16.37.0, filled with the brand color it lists | CC0 1.0 |
| `netease.svg` | Traced to vector from the touch icon NetEase Mail publishes at `mail.163.com/apple-touch-icon.png` | Trademark of NetEase, used only to name the service |
| All other `.svg` files | [Lobe Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.102.0) | MIT |

Each file has its `<title>` and size attributes removed and `aria-hidden` added. The visible name is rendered next to the logo.

Neither set has a NetEase Mail icon, so `netease.svg` was traced from the official one.
